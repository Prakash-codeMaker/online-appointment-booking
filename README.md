# Online Appointment Booking System

An Agile-based Online Appointment Booking System developed as a semester project using Scrum and Kanban practices.

## Problem Statement
Manual appointment scheduling can involve phone calls, unavailable time slots, duplicate bookings, and poor visibility of appointment status. This project aims to provide a simple digital workflow for customers and service providers.

## Objectives
- Allow users to register and log in.
- Search and view service providers.
- View available appointment slots.
- Book, cancel, and reschedule appointments.
- Provide dashboards for customers and providers.
- Demonstrate Scrum, Kanban, user stories, iterative development, testing, and version control.

## Agile Approach
The work is planned in four sprints:
1. Sprint 1 – Planning & Foundation
2. Sprint 2 – Users & Providers
3. Sprint 3 – Appointment Booking
4. Sprint 4 – Testing & Finalization

Kanban workflow:
**Backlog → To Do → In Progress → Code Review → Testing → Done**
