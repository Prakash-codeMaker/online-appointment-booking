# GitHub Project / Kanban Setup

The repository already contains the Agile issues, sprint mapping, labels, documentation, feature branches, and merged pull requests.

The remaining GitHub UI step is to create a Project board because the connected GitHub integration used for repository automation does not expose GitHub Projects board creation.

## Recommended Board
Create a **Board** project named:

Online Appointment Booking – Agile Project

Use these status columns:
- Backlog
- To Do
- In Progress
- Code Review
- Testing
- Done

Add the repository issues to the project. Use the issue body sprint names for Sprint 1–4 and the existing labels for categorization.

## Suggested Project Views
1. Kanban Board – status workflow
2. Sprint Table – issue, sprint, priority, assignee, status
3. Roadmap – Sprint 1 through Sprint 4

## Demonstration Flow
Open the repository → Issues → Project Board → Sprint/issue → Pull Request → merged code → Tests.

This produces a clear trace from requirement to implementation and testing.
