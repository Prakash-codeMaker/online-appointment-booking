# Agile Methodology Report

## 1. Project Overview
The Online Appointment Booking System is used to demonstrate Agile software development practices through Scrum and Kanban.

## 2. Why Agile?
Appointment software can evolve as users provide feedback. Agile allows the team to deliver small increments, inspect progress frequently, and reprioritize work.

## 3. Scrum Application
The project is divided into four sprints. Each sprint has a goal, selected backlog items, implementation work, review, testing, and a retrospective-oriented improvement step.

## 4. Kanban Application
The GitHub Project board uses:
Backlog → To Do → In Progress → Code Review → Testing → Done.

Issues represent units of work and move through the workflow as development progresses.

## 5. User Stories
Requirements are written from the user's perspective. Acceptance criteria are added so that completion is testable.

## 6. Version Control
Git branches and pull requests are used to isolate features and support review before merging into the main branch.

## 7. Quality Assurance
Unit, functional, integration, and regression testing are planned. Defects are tracked as issues and fixes are reviewed before completion.

## 8. Expected Learning Outcomes
This project demonstrates:
- difference between planned and iterative development;
- Agile roles and responsibilities;
- requirements elicitation and prioritization;
- Scrum artifacts and sprint lifecycle;
- Kanban workflow;
- user stories and acceptance tests;
- refactoring, review and continuous integration concepts;
- functional, unit, regression and automation-oriented testing.
